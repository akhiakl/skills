# Internationalization

- Plan for text expansion of 30% or more (German, Finnish) and contraction (Chinese, Japanese). No fixed-width buttons or labels.
- Logical properties everywhere (`margin-inline-start`, `inset-inline-end`, `text-align: start`). Test `dir="rtl"`.
- Mirror directional icons (arrows, back, progress) in RTL. Do not mirror media controls, clocks, logos or numbers.
- `Intl.DateTimeFormat`, `Intl.NumberFormat`, `Intl.RelativeTimeFormat`, `Intl.PluralRules` for all formatting. Never concatenate translated fragments.
- No text in images. Use CSS or SVG with real text.
- Font stacks must cover the target scripts; check line height for scripts with tall marks (Devanagari, Thai, Vietnamese).
- Language switcher shows each language in its own name. Detect from `Accept-Language`, never force by IP.
- `translate="no"` on brand names and code. `hreflang` links for localized pages.
