# Inspiration: borrow techniques, not looks

Before borrowing, name the technique and why it fits THIS product. Copying a famous look is the fastest way to look generic.

## SaaS and dev-tool landing
- **Linear**: real product UI as hero. One accent hue reserved for CTA, focus, links. Display cut with tight negative tracking at large sizes. Hairline borders over heavy shadows.
- **Stripe**: one signature brand moment (a lightweight WebGL gradient) inside fine typography. Jank-free motion as a standard. WAAPI for chained interactive sequences.
- **Vercel**: interactions prototyped in code, "no dropped frames" bar, 1px box-shadow rings as borders, paired sans and mono.
- **Raycast**: static light streaks give energy without animation. Layered shadows with inset highlights echoing the host OS. Testimonials naming each user's specific favorite feature.

## Consumer app marketing
- **Things 3**: progressive disclosure, purposeful custom animation, press quotes over feature grids.
- **Arc**: editorial serif voice in a tech category; drawn, flattened product mockups.
- **Apple**: pinned scroll scenes, image sequences drawn to canvas, static first frame under reduced motion.

## E-commerce
- **Aesop**: calm transitions mirroring the store, product pages that teach usage, understated copy, an extendable component system.
- **Scout Motors** (Awwwards E-commerce of the Year 2025): heritage story before the purchase prompt, 3D exploration beside a clear configurator path.
- General: product imagery as hero, price and key specs above the fold, sticky add-to-cart on mobile, fast filters with URL state.

## Portfolio and experiential
- **Lando Norris by OFF+BRAND** (Awwwards Site of the Year 2025): the subject's personality drives motion, bold type, a stated goal of performing as fast as it looks.
- **Messenger by abeto** (Awwwards Developer Site of the Year 2025): playful WebGL under a strict asset budget.
- Borrow the commitment to one idea, not the WebGL. Most portfolios need great type and pacing more than 3D.

## Dashboards and app screens
- Density with calm: tabular numbers, aligned columns, color only for status and selection.
- Keyboard-first: command palette, visible shortcuts, no animation on frequent actions.
- URL state for filters, tabs, pagination. Optimistic updates with undo.

## Docs
- **Stripe Docs**: docs that behave like an app, interactive components in content, API overlays on hover, three columns with code synced to prose, content validated as data.
- General: search first, copy buttons on code, anchored headings with `scroll-margin-top`, readable measure, visible "last updated".

## Fresh references
Awwwards (Sites of the Day, Sites of the Year), Godly, Land-book, One Page Love, Mobbin (app flows), Refero. Pick 2 or 3, write one sentence each on the technique to borrow, and state what you will do differently.
