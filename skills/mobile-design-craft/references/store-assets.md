# Store assets

- **App icon**: 1024x1024 source, no transparency for iOS; light, dark and tinted variants; Android adaptive icon (foreground and background layers, logo inside the safe zone) plus a monochrome layer for themed icons. Check Apple's current icon guidance for Liquid Glass before shipping.
- **Splash**: expo-splash-screen config plugin; logo on the brand background with a dark variant; no text, no spinner; hide when the first screen is ready.
- **Screenshots**: real product UI with a 3 to 6 word benefit headline per frame; the first two frames tell the story; real data, never lorem; localize headlines; include a dark-mode frame if it sells.
- **Name and subtitle**: plain benefit, no keyword stuffing.
