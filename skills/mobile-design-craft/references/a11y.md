# Accessibility

- `accessibilityRole` on every interactive element; `accessibilityLabel` on icon-only controls; `accessibilityHint` only when the result is not obvious; `accessibilityState` for selected, checked, disabled, expanded.
- Group card contents: `accessible` on the container with one combined label.
- Targets 44x44pt iOS, 48x48dp Android; `hitSlop` for small visuals.
- Dynamic Type: keep `allowFontScaling` on. Cap only dense chrome (tab labels, badges) with `maxFontSizeMultiplier` of 1.3 or more. Test at the largest accessibility size; let rows grow; switch horizontal rows to vertical when `PixelRatio.getFontScale()` is large.
- Color is never the only signal; pair with an icon or text.
- Respect Reduce Motion, Reduce Transparency, Bold Text and Increase Contrast.
- Focus order follows visual order; modals trap focus; announce async results with `AccessibilityInfo.announceForAccessibility`.
- Test the main flow with VoiceOver and TalkBack, at the largest text size, in dark mode, and in RTL if localized.
